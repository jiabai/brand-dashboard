# 平台租户管理员入口位置修正

## 背景

平台租户列表曾把“租户管理员”和“详情”作为操作列中的两个并列按钮。虽然二者分别指向详情页锚点和详情页顶部，但从平台管理员视角看，它们都进入同一个详情页面，容易造成重复入口和功能边界不清。

## 变更

- 操作列只保留“详情”按钮，作为租户整体详情主入口。
- 管理员列继续展示管理员姓名、邮箱、手机号和状态，并在该列内提供轻量“查看”入口。
- 管理员列“查看”入口仍跳转到 `/platform/tenants/:tenantKey#tenant-admin`。
- 保持平台管理员只读边界，不新增租户管理员编辑、重置密码或重新发送激活邮件等写操作。
