# Phase 3.2 项目 API 落地
> 日期：2026-06-07
> 类型：api, tests, architecture

## 变更

- 新增 `api/v1/routes/projects.py`，提供项目列表、创建、详情、品牌配置和问题集配置接口。
- 新增 `api/v1/repositories/projects.py` 和 `api/v1/services/projects.py`，保持 Routes → Services → Repositories 分层。
- 在 `api/v1/models/schemas.py` 新增项目相关 Pydantic 契约，请求体禁止携带 `tenant_key`。
- 在 `api/main.py` 和 `api/v1/routes/__init__.py` 注册 `/api/v1/projects` 路由。
- 新增 `api/tests/test_projects_api.py`，覆盖认证、租户过滤、admin 写权限、请求体租户字段拒绝、详情聚合、品牌配置 upsert 和问题集配置。
- 更新领域模型参考、active ExecPlan 和 `TASKS.md`。
