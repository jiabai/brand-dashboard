# 移除账户管理页管理员激活入口

## 变更摘要

- 从登录后的 `AccountManagement` 页面移除“管理员激活”tab、激活表单和 `activateAuth` 调用。
- 保留 `/activate?token=...` 公开激活页作为租户管理员首次设置密码的正式入口。
- 更新账户管理页文案，明确该页只承载员工注册、邀请码核验、登录辅助和平台租户管理跳转。
- 新增前端守护测试，防止登录后的账户管理页重新引入管理员激活流程。

## 原因

管理员首次激活发生在登录前，依赖邮件中的一次性激活链接；登录后的租户工作台不应承载该流程，否则会混淆平台管理员、租户管理员和普通租户成员的使用路径。
