# Code of Conduct

## Our Standard

We aim to keep this project practical, respectful and focused. Contributors should communicate clearly, assume good intent, and make room for different levels of experience.

## Expected Behavior

- Be respectful in issues, reviews and discussions.
- Keep feedback specific to code, documentation, tests or project outcomes.
- Explain tradeoffs and risks without personal attacks.
- Protect secrets, customer data and private operational details.

## Unacceptable Behavior

- Harassment, intimidation or discriminatory language.
- Publishing private information without permission.
- Deliberately committing secrets, destructive scripts or misleading documentation.
- Repeatedly ignoring maintainer guidance or project safety rules.

## Reporting

If you see a problem, open a private maintainer channel when available, or create a GitHub issue with only the minimum safe details needed to describe the concern. Do not include secrets or sensitive data in public reports.

## Enforcement

Maintainers may edit or remove harmful content, close discussions, restrict participation or take other reasonable action to keep the project safe and useful.
