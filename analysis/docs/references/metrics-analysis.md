# 指标解析 (Metrics Analysis)

本文档详细解释了 Brand Analysis 系统中使用的各项分析指标。

## 核心指标

### 1. 提及率 (Mention Rate)

**定义**: 文件级别的品牌提及指标。

- **计算方式**: 在分析的文档集合中，提及目标品牌的文件数量 / 总文件数量。
- **含义**: 反映了品牌在特定语料库或上下文中的可见度。数值为 1 表示所有文件都提到了该品牌，为 0 表示没有文件提到。

### 2. 首位提及率 (First Mention Rate)

**定义**: 衡量在列举多个品牌时，目标品牌被第一个提到的比例。

- **含义**: 这反映了品牌在 AI 认知中的"首要地位" (Top-of-Mind Awareness)。较高的首位提及率通常意味着品牌在该领域具有较强的领导地位或代表性。

### 3. 正面情绪占比 (Positive Sentiment Rate)

**定义**: 衡量大模型提及目标品牌时，使用积极、褒义描述的比例。

- **含义**: 数值越高，说明 AI 对该品牌抱有越正面的印象。这是衡量品牌美誉度的重要指标。

### 4. 负面情绪占比 (Negative Sentiment Rate)

**定义**: 衡量大模型提及目标品牌时，使用消极、贬义描述的比例。

- **含义**: 数值高是一个关键警报，表明存在需要干预的负面认知或品牌危机风险。

## 补充说明

> **注意**: 正面情绪占比与负面情绪占比之和通常小于 100%。这是因为模型生成的内容中存在大量客观、中立的情感描述，这些既不计入正面也不计入负面。
