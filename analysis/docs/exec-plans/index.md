# Exec Plans

## Purpose

ExecPlans capture task-specific implementation intent, progress, recovery context, validation results and retrospective notes.

## Entry Points

- Active plans: `active/index.md`
- Completed plans: `completed/index.md`
- Shared debt list: `tech-debt-tracker.md`

## Rules

- Keep active work in `active/`.
- Move completed or cancelled work to `completed/`.
- Capture cross-cutting debt in `tech-debt-tracker.md`.
- Do not use ExecPlans for tiny typo fixes or isolated low-risk edits.
