# 品牌分析仪表板

一个现代化的 React 仪表板应用，用于展示品牌分析数据和统计信息。采用先进的视觉效果和交互设计，提供沉浸式的数据分析体验。

## 功能特性

- 📊 **实时数据展示** - 显示品牌提及率、AI 模型使用率等关键指标
- ⏱️ **时间筛选** - 支持昨天、过去7天、过去30天的时间范围选择
- 📈 **可视化图表** - 环形进度图、进度条等多种数据可视化方式
- 🎨 **现代化设计** - 采用渐变色彩和毛玻璃效果的现代 UI 设计
- 📱 **响应式布局** - 完美适配桌面和移动设备
- 🛡️ **错误处理** - 完善的错误边界和加载状态管理
- ✨ **动态背景** - Canvas 驱动的动态网格背景效果
- 🎯 **粘性导航** - Gooey 效果的创新导航菜单
- 🌟 **微交互动画** - 丰富的悬停效果和过渡动画

## 技术栈

- **React 18.2.0** - 现代 React 函数组件和 Hooks
- **Vite 5.0.8** - 快速的构建工具
- **CSS3** - 使用 CSS 变量和现代 CSS 特性
- **PropTypes** - 类型检查和组件文档
- **Canvas API** - 动态背景网格动画
- **Radix UI** - 无障碍访问组件库
- **Tailwind CSS** - 实用优先的 CSS 框架
- **Lucide React** - 现代化图标库

## 开发指南

### 添加新组件

1. 在 `src/components/` 目录下创建组件文件
2. 使用 PropTypes 进行类型定义
3. 添加适当的 JSDoc 注释
4. 遵循现有的代码风格

### 样式开发

- 使用 `index.css` 中定义的 CSS 变量
- 遵循 BEM 命名规范
- 确保响应式兼容性
- 添加适当的过渡动画

### 数据管理

当前版本使用模拟数据，如需集成真实 API：
1. 在 `utils/index.js` 中添加数据获取函数
2. 更新组件状态管理
3. 添加加载和错误处理

### 动画优化

- 使用 `requestAnimationFrame` 优化 Canvas 动画性能
- 合理使用 CSS 过渡和动画
- 避免不必要的重绘和重排
- 使用 `transform` 和 `opacity` 进行动画优化

## 特色功能详解

### GooeyNav 导航效果
创新的粘性导航菜单，具有以下特点：
- 使用 SVG 滤镜创建独特的粘性变形效果
- 粒子爆炸动画增强交互体验
- 支持键盘导航和屏幕阅读器
- 完全可定制的颜色主题

### Squares 动态背景
高性能的 Canvas 动画背景：
- 响应式网格系统，自动适配屏幕尺寸
- 鼠标悬停高亮效果
- 支持多种移动方向（上下左右、对角线）
- 渐变遮罩营造深度感

### 毛玻璃效果
现代化的视觉设计元素：
- 使用 `backdrop-filter` 实现真实的毛玻璃效果
- 半透明背景和模糊边框
- 动态阴影和高光增强立体感
- 渐变色彩营造现代感
